# 🧵 Fabric Defect Detection System

> **An AI-powered fabric inspection system that uses Computer Vision and Deep Learning to automatically detect, classify, and analyze defects in textile images, enabling smarter and more efficient quality control.**

## 🌍 Overview

Manual fabric inspection is often time-consuming, inconsistent, and prone to human error. This project aims to automate the quality inspection process by leveraging **Computer Vision** and **Deep Learning** to identify defects in fabric samples with greater speed and accuracy.

The system is capable of detecting various defects such as **holes, stains, knots, and irregular patterns**, while also identifying their type, shape, severity, and approximate defect area in pixels. To provide a complete user experience, the project includes both a **Flask-based web application** for a production-like interface and a **Streamlit application** for rapid testing and demonstrations.

This project demonstrates how AI can enhance quality assurance in textile manufacturing by enabling reliable, scalable, and automated fabric inspection.

---

## ✨ Key Features

- 🧵 Automated fabric defect detection using AI
- 🔍 Detects multiple defect types including holes, stains, knots, and thread irregularities
- 📊 Identifies defect type, shape, severity, and estimated defect area
- 🖼️ Image preprocessing and feature extraction using OpenCV
- 🌐 Flask-based web application for interactive inspection
- ⚡ Streamlit interface for rapid testing and live demonstrations
- 🤖 Deep learning-powered defect classification for improved inspection accuracy
