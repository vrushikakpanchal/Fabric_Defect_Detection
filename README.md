# Fabric Defect Detection

An AI-based Fabric Defect Detection system developed using Computer Vision and Deep Learning to automatically identify defects in textile images. This project helps in improving quality control by detecting defects such as holes, stains, and irregular patterns in fabric samples.

## Features

- Automated fabric defect detection using image analysis  
- Deep learning-based classification of defective and non-defective fabric  
- Image preprocessing and feature extraction using OpenCV  
- Supports multiple fabric defect types (holes, stains, thread issues, etc.)  
- Improves inspection accuracy compared to manual quality checking  

## Technologies Used

- Python  
- Convolutional Neural Network (CNN)  
- Computer Vision  
- OpenCV (image preprocessing and analysis)  
- NumPy, Pandas, Matplotlib  
- Jupyter Notebook / Python Scripts
